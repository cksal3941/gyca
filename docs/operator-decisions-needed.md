# 운영 결정 요청서 (Claude → 사용자)

작성: Claude · 기준: `docs/claude-fullstack-work-order-2026-09-19.md` §12 · 갱신 누적
목적: 코드·어댑터·관리 화면·로컬 테스트는 계속 진행하되, **외부 계정·계약·운영 정책·법적 문구·실자료**처럼 사용자만 확정할 수 있는 항목을 한 번에 모아 요청합니다.

> 규칙: 비밀번호/비밀 키는 여기에 적지 마세요(채팅에도 요청하지 않습니다). 값은 확정되면 관리 화면에서 입력하거나 안전한 경로로 전달합니다. 아래는 "무엇을 정해야 하는지"의 목록입니다.

---

## 왜 지금 필요한가 — 공모 오픈 게이팅(실측)
로컬에서 공모 생성→오픈을 실제로 돌려보니, `open-applications`는 아래 **launch-readiness 체크가 전부 충족**돼야만 열립니다(미충족 시 503로 정확히 차단됨). 굵은 항목이 사용자 결정에 달려 있습니다.

| readiness 체크 | 의미 | 사용자 결정 필요? |
| --- | --- | --- |
| public_content | 제목·기간·시간대·참가비 등 | 값 확정 필요(아래 B) |
| published | 공개 여부 | 운영 판단 |
| schedule | 접수 시작/마감/결제마감 | **마감 시각·시간대·결제유예(아래 C)** |
| form | 부문·연령·입력 필드·업로드 규격 | **필수 필드·파일 형식(아래 D)** |
| consents | 참가규정/개인정보/작품이용허락 문서·버전 | **승인 문구·버전(아래 E)** |
| guardian_policy | 보호자 연령 기준·확인 방식 | **국가별 정책(아래 E)** |
| payment_policy / payment_routes | 결제 정책·경로 | **PG·통화(아래 A)** |
| storage / retention / live_payment_verification | 저장소·보관·실결제 외부 검증 증거 | **외부 계정·검증(아래 A·F)** |

---

## A. 결제(PG)·통화 — 최우선
- 계약 **사업자 국가·법인명**, PG(예: Toss 계열 해외결제 등) **신청/계약 상태**.
- 원하는 **청구·정산 통화**(현재 계약은 €70 = EUR 7000 minor 기준). EUR 청구가 가능한 PG인지, 아니면 통화 변경/별도 국제 공급자 도입 여부.
- **해외 발급 카드/참가 국가 범위**(해외 참가자 결제 허용 범위), 환불 방식.
- (근거·조사는 확정 시 `docs/payment-provider-decision.md`에 조사일·공식 출처와 함께 기록 예정. 임의 환율·국가 추정으로 결정하지 않음.)

## B. 공모 기본 정보
- 처음 오픈할 공모(현재 seed는 Leipzig 2027) 확정, 제목 EN/KO, 참가비(작품당 금액·통화).
- 시간대(현재 Europe/Berlin 가정) 확정.

## C. 일정·접수 성립
- 제출 **마감 시각·시간대**, 결제 유예 시간, **접수 성립 기준**(submitted vs 결제완료 vs received).
- 10월 초 **정확한 목표 오픈일**.
- 참가비·**환불 규정**.

## D. 폼·파일 규격
- **부문(카테고리)·연령 구분**(연령 기준일 포함).
- 필수 입력 항목(영문 작품명/소개, 참가자 영문명·학년 필수 여부 등).
- 업로드 규격: 허용 파일 형식(예: 표지 이미지, 도서 PDF), **최대 용량·최소 페이지 수**, 파일 개수.

## E. 법적 문구·동의·보호자
- **참가 규정 / 개인정보 수집·이용 / 작품 이용허락**의 승인 문구·버전·공개 범위.
- **국가별 보호자 연령 기준·확인 방식**(동의 근거·적용 조건 검토한 운영 결정. "유럽은 모두 16세" 같은 단순 규칙으로 확정하지 않음).
- 파일·개인정보·동의 증적 **보관 기간**.

## F. 외부 계정·인프라
- 사용할 **클라우드/DB/저장소(S3)/메일** 계정 준비 여부와 관리자 초대 방식.
- storage/retention/실결제(live_payment) **외부 검증 증거**(관리 화면에서 evidenceReference·유효기간으로 등록; 실제 검증 없이는 "준비 중" 유지).

## G. 표시·자료
- 전시 명칭·장소 승인 여부, 사업자 표시 정보(상호/대표/사업자번호/통신판매/호스팅), 고객지원 연락처, 요강 PDF.
- 아카이브(Klimt Villa 등) 공개 가능한 실제 사진·인터뷰·인증서·실적 자료.

## 진행 상황(사용자 응답 대기 중에도 계속)
- 어댑터·관리 화면 뼈대·로컬 테스트·배포 준비는 계속 진행합니다.
- 위 값이 확정되면 공모 등록/정책/오픈 화면에서 입력 → launch-readiness 충족 → 오픈 처리합니다.
