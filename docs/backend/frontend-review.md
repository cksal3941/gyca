# 프런트엔드 현재 상태 점검

검토 대상: 현재 로컬 작업 트리와 실행 중인 http://localhost:3000. 과거 배포 주소의 현재 상태를 확인한 결과는 아니다. 프런트 코드는 수정하지 않았다.

## 결론

### 후속 대응 확인

Claude가 frontend-handoff.md §8에 기록한 대응을 소스와 대조했다. ApplyCta.tsx의 데모 안내, submit/page.tsx의 서버 미저장/새로고침 초기화 안내, Footer.tsx의 샘플 사업자 정보 제거와 준비 중 표기를 확인했다. 아래 최초 지적 중 해당 문구 문제는 수정됐다. 홈 CTA는 여전히 open-ready mock을 사용하므로 실제 서버 상태 연동까지 완료된 것은 아니다. 이번 후속 확인은 문서·소스 기준이며 렌더링과 전체 링크를 재검증하지 않았다. Claude 개인 메모리는 확인하지 않았다. 아카이브 실자료 확보는 콘텐츠 준비 작업이며 백엔드 구현만으로 해결되는 항목이 아니다.

화면/데모 구현은 상당 부분 진행됐으며, 실서비스 완료 판정은 불가하다. Claude의 docs/frontend-handoff.md도 접수·결제·관리자·심사 실연결 0, 인증만 Better Auth 구성이라고 명시한다. src/lib/api/index.ts, ops.ts, submit-machine.ts의 mock 구현과 일치한다. 이번 검토에서 실제 로그인은 시험하지 않았다.

## 직접 확인

- 홈: 이미지 히어로, 공모 안내, 아카이브 연결, 접수 CTA 렌더링. 현재 브라우저 폭에서 상단 외관 확인.
- 접수: Resume draft → 작품 → 파일 → 확인/동의 이동. 필수 파일/동의 누락 시 Submit 비활성화. 참가 규정/개인정보/작품 이용허락 분리, 선택 홍보는 demo-only 표기.
- 관리자: 14건 샘플 목록, 검색/필터/페이지/일괄 작업 컨트롤 렌더링. 검색·일괄 실행 자체는 이번에 전수 검증하지 않음.
- 심사: 배정 목록과 rev_1 상세 렌더링. 이름 대신 블라인드 코드. PDF 뷰어는 mock이고 새 창 링크는 #.
- 마이페이지: 탭 및 Empty 시나리오에서 빈 안내와 공모 링크 확인.
- 클림트: 완료 프로젝트/아카이브 표시, 요청한 10개 항목 구조, 모집 CTA 없음. 대부분 실제 자료는 Content pending.
- 전체 TypeScript 검사 재실행 통과.

## 출시 전 우선 조치

1. 실제 API 연결: index.ts/ops.ts/submit-machine.ts를 서버 계약에 맞춰 교체. 서버에 없는 심사·결과 일괄 발표·인증서·CSV 기능은 프런트 데모 완료와 별도로 구현해야 한다. 서버만의 잘못도, 프런트만의 누락도 아닌 통합 잔여 작업이다.
2. 공개 홈 CTA: 현재 Apply Now는 서버 비활성 상태와 무관하게 보인다. 실제 Competition.status/readiness/allowedActions에 연결하기 전에는 실접수 가능으로 표현하지 않는다. src/components/home/ApplyCta.tsx 기본값은 open-ready mock.
3. 저장 안내: submit/page.tsx:153~154는 서버 저장·새로고침 복원을 확정적으로 안내하지만 현재 useSubmitFlow는 메모리 mock이다. 실제 저장 연결 전에는 데모임을 문장에도 명시해야 한다.
4. 심사 PDF와 권한: ReviewEditor.tsx의 PDF는 placeholder. 블라인드 배정·파일 접근 및 PDF 내부 식별정보 처리는 실제 서버 작업으로 검증해야 한다.
5. 공개 콘텐츠: Footer.tsx에 Gildong Hong/0000 형태 사업자 샘플, NewsUpdate.tsx 등에 # 링크가 남아 있다. 실제 정보/목적지로 교체하거나 준비 중 처리한다.
6. 아카이브 실자료: 선정작/현장사진/판매사례/인터뷰/인증서/실적 확보 및 입력이 필요하다.
7. 최신 서버 계약: 제출 기록·동의 이력·다운로드·결제 운영 조회 등의 연결은 아직 확인되지 않는다. backend/claude-handoff.md를 기준으로 어댑터 연결 순서를 확정한다.

## 검증 한계

이번 검토는 대표 화면과 코드의 실연결 여부 확인이다. 모든 해상도/EN·KO/키보드 접근성/모든 오류 시나리오/결제 전체 과정을 통과한 QA가 아니다. 프로덕션 빌드는 이번에 실행하지 않았으며 Claude 문서에는 Turbopack 환경 오류로 미완료라고 기록돼 있다. 이를 검증 완료로 바꾸지 않았다. 개발 서버는 이미 실행 중인 것을 사용했고 종료하거나 재설정하지 않았다.
